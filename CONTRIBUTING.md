# Contributing

Open an issue explaining the proposed change and the evidence it addresses. Use Python 3.11 and a virtual environment. Run `python -m pytest -q` and `python -m compileall -q src` before proposing a change.

Keep datasets, credentials, personal photographs, model binaries, and generated training artifacts out of commits. Do not add notebook outputs containing data images. Describe experiment data, split, environment, selection metric, and actual results; never replace missing runs with estimates. New contributions are under this repository's AGPL-3.0 license.
